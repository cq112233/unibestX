# 更新日志

## 1.0.0 (2026-10-16)

### 🚀 特性发布

- **全平台导航守卫**：支持标准 Vue Router 风格的 `beforeEach((to, from, next) => { ... })`；
- **手势返回精准拦截**：攻克微信小程序 `onAppRoute` 与支付宝小程序原生侧滑手势返回，自动触发守卫；
- **页面快照隔离**：首创快照隔离引擎，彻底解决 App 页面进入动画期间上一页路由被提前冲刷覆盖的问题；
- **原生 TabBar 模式兼容**：支持自定义与原生 TabBar 无缝跳转；
- **零构建包袱**：纯 UTS 强类型运行时架构，零构建配置要求。
